# تطبيق مصروفي الذكي (Masroufi AI) 📱💰
### نظام متقدم لتتبع الدخل والمشتريات وكشف الهدر المالي عبر رسائل البنوك والذكاء الاصطناعي

تطبيق أندرويد عصري مبني بأحدث التقنيات (`Kotlin`, `Jetpack Compose`, `Material 3`, `Room Database`, `Gemini Multimodal AI`).

---

## 🌟 الميزات الرئيسية المحققة

### 1. التعرف الذكي على رسائل البنوك (Bank SMS Engine)
- **حوالات محلية واردة**: يتعرف على نصوص الحوالات والإيداعات والرواتب ويضيفها لرصيد الدخل.
- **حوالات محلية صادرة**: يميز الحوالات السريعة والمحلية ويحدد الطرف المستفيد.
- **عمليات الشراء (POS)**: يميز عمليات نقاط البيع في المتاجر والمطاعم والكافيهات.
- **عمليات الشراء عبر الإنترنت**: يتعرف على متاجر التجارة الإلكترونية مثل Amazon, Noon, إلخ.
- **تحديد نوع البطاقة والوسيلة**:
  - بطاقات **مدى (mada)**
  - بطاقات **فيزا (Visa)**
  - بطاقات **ماستركارد (Mastercard)**
  - بطاقات ائتمانية وحسم فوري ومسبقة الدفع
  - استخراج آخر 4 أرقام من البطاقة أو الحساب (مثل `*4432`)

### 2. فحص الفواتير وتصنيف البنود (Receipt OCR & AI Classifier)
- إمكانية تصوير فاتورة المشتريات الورقية أو الإلكترونية بالكاميرا.
- تحليل محتويات الفاتورة صنفاً صنفاً عبر الذكاء الاصطناعي متعدد الوسائط.
- تصنيف كل سلعة إلى:
  - **ضروري وأساسي 🟢**: (أغذية رئيسية، أدوية، منظفات أساسية، فواتير).
  - **هدر وكماليات 🔴**: (حلويات، مشروبات طاقة وسكرية، سناكات، كماليات ترفيهية).
- حساب نسبة الهدر داخل الفاتورة مع تقديم نصيحة توفير مخصصة.

### 3. المستشار المالي وسؤال المستخدم لتحديد الهدر (Interactive Waste Coach)
- مراقبة أنماط الصرف شهرياً.
- توجيه أسئلة ذكية ومباشرة للمستخدم داخل التطبيق وعبر الإشعارات:
  - *"صرفت 120 ر.س في كافيه.. هل تعتبرها ضرورية أم هدر يمكن تجنبه؟"*
  - *"عملية شراء بـ 480 ر.س عبر الإنترنت.. هل كانت سلعة أساسية أم هدر اندفاعي؟"*
- تحديث **مؤشر الهدر الشهري (Waste Gauge)** تلقائياً بناءً على إجابات المستخدم وفواتيره.

## 🏗️ البنية المعمارية للمشروع (Clean Architecture)

```
com.masroufi.app/
│
├── data/
│   ├── model/         # نماذج البيانات (TransactionEntity, CardType, ReceiptItem, ...)
│   ├── local/         # قاعدة بيانات Room (AppDatabase, TransactionDao, Converters)
│   └── repository/    # مستودع البيانات وحسابات تقارير الهدر الشهري
│
├── parser/            # محرك التعرف على نصوص رسائل البنوك (BankSmsParser)
├── receiver/          # مستقبل الرسائل في الخلفية (BankSmsReceiver)
├── ai/                # خدمة فحص الفواتير (ReceiptAnalyzerService) والمستشار المالي (FinancialCoachAdvisor)
├── viewmodel/         # MainViewModel لإدارة حالة الواجهة والبيانات
│
└── ui/
    ├── theme/         # ألوان وتصميم Material 3 متوافق مع الاتجاه العربي (RTL)
    ├── components/    # البطاقات التفاعلية، مؤشر الهدر، نافذة الفاتورة، محاكي الرسائل
    └── screens/       # شاشة العرض الرئيسية (HomeScreen)
```

## 🚀 كيفية تشغيل واختبار التطبيق
1. افتح المجلد في **Android Studio**.
2. يمكنك تجربة الرسائل البنكية فورياً عبر زر **محاكاة رسائل البنك (SMS)** المدمج في التطبيق لتجربة كافة السيناريوهات.
3. يمكنك تجربة تصوير الفواتير عبر الضغط على الزر العائم **فحص فاتورة وتقسيمها 🧾**.
